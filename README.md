# Frontline Desktop Releases

Official release repository for the Frontline desktop application.

## Downloads

Download the latest version from the [Releases](../../releases/latest) page.

Supported platforms:

- macOS — Apple Silicon and Intel
- Windows — x64

## Security

Production installers are code-signed and include SHA-256 checksums.

Do not download Frontline installers from unofficial sources. Draft and unsigned builds are used only for internal testing and are never published as production releases.

## Source code

The application source code is maintained in Frontline's private Bitbucket repository. This public repository contains only release artifacts and update metadata.
